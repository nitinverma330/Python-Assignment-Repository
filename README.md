# Python-Assignment-Repository

A comprehensive collection of Python assignments, coursework tasks, and practical exercises covering core to intermediate Python programming concepts.

## 📚 Notebooks Included

1. **[Operators.ipynb](Operators.ipynb)**: Arithmetic, Compound Assignment, Relational, Logical (`and`, `or`, `not`), Identity (`is`, `is not` vs `==`), Membership (`in`, `not in`), and Python's increment/decrement semantics.
2. **[Conditional Statements Tasks.ipynb](Conditional%20Statements%20Tasks.ipynb)**: Real-world problems including ATM Withdrawal, Electricity Bill Calculation with Surcharge, Employee Bonus Eligibility, Student Result System, Bank Loan Eligibility, E-Commerce Discounts, and Role-Based Access Control.
3. **[Loop Tasks.ipynb](Loop%20Tasks.ipynb)**: 17 complete exercises covering `for` and `while` loops, number series, accumulator sums, multiplication tables, list filtering, and string processing.
4. **[Pattern Printing.ipynb](Pattern%20Printing.ipynb)**: 16 pattern printing programs using nested loops (star triangles, numbers, Floyd's triangle, binary alternating, alphabets, centered pyramids, diamonds, and while loop patterns).
5. **[String Methods.ipynb](String%20Methods.ipynb)**: String indexing, slicing, reversal, repetition, formatting (f-strings, `.format()`), case manipulation, whitespace stripping, searching, and character validation.
6. **[Tuples and Sets.ipynb](Tuples%20and%20Sets.ipynb)**: Tuple immutability, packing, unpacking, methods; Set creation, uniqueness, modification, and mathematical set operations (union, intersection, difference).
7. **[Dictionary Tasks.ipynb](Dictionary%20Tasks.ipynb)**: Dictionary methods, mutability, copy vs reference, and 10 practical tasks (grading, stock inventory, department classification, exam eligibility, and bank accounts).
8. **[List Comprehension Tasks.ipynb](List%20Comprehension%20Tasks.ipynb)**: 17 list comprehension challenges covering filtering, transformations, conditionals, financial transactions, and multi-criteria queries.
9. **[QR Code and OCR.ipynb](QR%20Code%20and%20OCR.ipynb)**: QR Code generation (`qrcode`), custom styling, dynamic UPI payment QR codes, and OCR image-to-text extraction pipeline with `pytesseract`.
10. **Pre-existing Coursework Notebooks**:
    - `Conditional Statement.ipynb`
    - `Dictionary.ipynb`
    - `List Comprehension.ipynb`
    - `Loops.ipynb`
    - `Python List.ipynb`

## 📁 Folder Structure

- `*.ipynb`: Interactive Jupyter Notebooks with problem statements, solutions, and sample outputs.
